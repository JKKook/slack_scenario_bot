# Slack Scenario Bot

YouTube Short 시나리오를 자동으로 생성하고 감정이 풍부한 한국어 TTS 음성 파일을 제공하는 슬랙 봇입니다.

## 주요 기능

-   🎥 **YouTube Short 시나리오 생성**: 주제와 내용을 입력하면 1분짜리 시나리오를 자동 생성
-   🎵 **감정 풍부한 한국어 TTS 변환**: gTTS를 사용한 어조별 감정 표현 음성 변환
-   🎭 **어조별 음성 스타일**: 친근함, 유머, 영감, 교육, 전문성에 따른 음성 톤 자동 조절
-   📁 **MP3 파일 생성**: 음성 파일을 MP3 형식으로 생성
-   📤 **슬랙 파일 업로드**: 생성된 MP3 파일을 슬랙 채널에 자동 업로드
-   🌐 **웹 인터페이스**: 로컬에서 시나리오 생성 및 음성 파일 다운로드 가능

## 설정

-   **Command**: `/scenario`
-   **URL**: `${ngrok}/slack/chat`
-   **Port**:
    -   Backend: 5001
    -   Frontend: 3000

## 사용법

### 1. 슬랙 봇 사용

슬랙에서 `/scenario` 명령어를 사용하여 시나리오를 생성할 수 있습니다:

#### 입력 형식

1. **쉼표로 구분**: `주제, 상세내용`

    - 예: `AI의 미래, AI가 경제생활에 미치는 영향`

2. **구조화된 형식**:
    ```
    주제: AI의 미래
    상세내용: AI가 경제생활에 미치는 영향
    ```

#### 출력 결과

-   📝 **텍스트 시나리오**: 시작, 본문, 마무리로 구성된 상세한 시나리오
-   🎵 **감정 풍부한 음성 파일**: 어조에 맞는 자연스러운 한국어 음성 (슬랙에서 다운로드 가능)

### 2. 웹 인터페이스 사용

로컬에서 웹 브라우저를 통해 시나리오를 생성하고 음성 파일을 다운로드할 수 있습니다.

#### 실행 방법

1. **백엔드 서버 실행**:

    ```bash
    python3 slack_app.py
    ```

2. **프론트엔드 실행**:

    ```bash
    cd client
    npm install
    npm start
    ```

3. **브라우저에서 접속**:

    ```
    http://localhost:3000
    ```

#### 웹 인터페이스 기능

-   📝 **주제와 상세 내용 입력**
-   🎵 **시나리오 생성 및 감정 풍부한 음성 변환**
-   📥 **음성 파일 재생 및 다운로드**
-   📋 **생성된 시나리오 상세 보기**

## 감정 표현 TTS 기능

### 어조별 음성 스타일

시스템이 자동으로 어조를 분석하여 적절한 감정 표현을 적용합니다:

-   **친근하고 일상적인 어조**:

    -   감정 단어 추가: "진짜", "완전", "쉽게 말하면"
    -   빠른 속도, 친근한 톤
    -   예: "진짜 AI가 우리 삶을 바꾸고 있어!"

-   **유머러스하고 재미있는 어조**:

    -   감정 단어 추가: "완전", "대박", "쩔어"
    -   빠른 속도, 경쾌한 톤
    -   예: "완전 대박! 이거 진짜 웃겨!"

-   **영감을 주고 동기부여가 되는 어조**:

    -   감정 단어 추가: "너도", "할 수 있어", "지금"
    -   빠른 속도, 열정적인 톤
    -   예: "너도 할 수 있어! 지금 시작해!"

-   **교육적이고 설명적인 어조**:

    -   감정 단어 추가: "쉽게 말하면", "예를 들어"
    -   천천히 말하기, 차분한 톤
    -   예: "쉽게 말하면, 이건 이렇게 작동해."

-   **전문적이고 격식있는 어조**:
    -   감정 단어 추가: "분명히", "확실히"
    -   천천히 말하기, 신뢰감 있는 톤
    -   예: "분명히 이 기술은 시장을 혁신합니다."

### 감정 표현 기법

1. **텍스트 전처리**: 어조에 맞는 감정 단어 자동 추가
2. **구두점 조절**: 감정 강도에 따라 느낌표(!) 자동 추가
3. **속도 조절**: 교육적/전문적 어조는 천천히 말하기
4. **문장 강조**: 핵심 메시지에 감정 표현 강화

## 설치 및 실행

### 1. 백엔드 설정

```bash
# 패키지 설치
pip3 install flask slack-bolt flask-cors python-dotenv openai gtts

# 서버 실행
python3 slack_app.py
```

### 2. 프론트엔드 설정

```bash
# client 폴더로 이동
cd client

# 의존성 설치
npm install

# 개발 서버 실행
npm start
```

### 3. ngrok 터널링 (로컬 개발용)

```bash
ngrok http 5001
```

## 기술 스택

-   **Backend**: Flask, Slack Bolt
-   **Frontend**: React, Axios
-   **AI**: OpenAI GPT-4
-   **TTS**: Google Text-to-Speech (gTTS) - 감정 표현 고도화
-   **Language**: Python 3.11+, JavaScript
